## Этап 3: CRM Аддитив Плюс - MVP v1.0
**Дата:** ~15.05.2026
**Статус:** ✅ MVP создан, развитие продолжается

**Задача:** Создать модульную CRM/ERP-систему для Аддитив Плюс, объединяющую все отделы компании: продажи, бухгалтерию, лабораторию, логистику, техподдержку и IT.

**Стек:** Vue 3 + Vite + Tailwind CSS, шрифты Outfit + Cormorant Garamond

**Архитектура модулей:**
- Карточка клиента (ядро)
- Сделка (продажи) - воронка: Лид → Квалификация → Предложение → Переговоры → Закрытие
- Счёт/Оплата (бухгалтерия)
- Заявка в лабораторию (R&D)
- Отгрузка (логистика)
- Тикет (техподдержка)

**Ролевая модель:** Админ, Руководитель, Менеджер продаж, Бухгалтер, Лаборант, Логист, Техподдержка
