# Ретроспективы

Рефлексия после каждой важной сессии. Помогает отслеживать прогресс, фиксировать ошибки и накапливать опыт.

## Формат файла

```
YYYY-MM-DD_HH-MM_краткое-описание.md
```

Пример: `2026-05-15_21-00_каталог-добавок.md`

## Как пользоваться

1. В конце каждой сессии создай файл по шаблону `TEMPLATE.md`.
2. Заполни все разделы честно - это для твоего роста, не для отчёта.
3. Если научился чему-то новому - обязательно запиши в `ai-clone/feedback/`.
