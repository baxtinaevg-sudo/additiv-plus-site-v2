# Папка plans/

Место для технических планов реализации функций проекта.

**Правила:**

1. Один план = одна функция. Если план уже существует — работаем с ним, не создаём дубликат.
2. Формат имени файла: `YYYY-MM-DD-название-функции.md` (пример: `2026-05-15-модуль-отчётов.md`).
3. Каждый план делится на фазы. У каждой фазы статус `[ ]` (не начато) или `[x]` (выполнено).
4. В конце плана — итоговый блок: реализован целиком или нет, что осталось сделать.
5. Любой агент обязан актуализировать план **после каждой сессии**: отмечать выполненные фазы, фиксировать результаты.
6. **Цикл работы с планом:**
   - Первый чат — формирует черновик плана.
   - Второй чат — разбивает план на фазы.
   - Третий чат — проверяет каждую фазу на адекватность и выполнимость.
   - Только после трёх этапов — приступаем к реализации.
