# Каталог химических добавок для ССС — Инструкции

## Обзор

Каталог химических добавок для сухих строительных смесей компании Аддитив Плюс.

## Структура файлов

```
catalog-sss/
├── structure.md   — Полное содержание каталога (источник истины)
├── preview.html   — HTML-макет для просмотра в браузере и генерации PDF
└── README.md      — Этот файл с инструкциями
```

## Просмотр каталога

### Вариант 1: Открыть в браузере
Просто откройте файл `preview.html` в любом современном браузере:
- Chrome/Edge
- Firefox
- Safari

### Вариант 2: Локальный сервер (опционально)
```bash
# Python 3
python -m http.server 8000

# Затем открыть http://localhost:8000/.business/marketing/catalog-sss/preview.html
```

## Генерация PDF

### Способ 1: Печать из браузера (рекомендуется)

1. Откройте `preview.html` в браузере
2. Нажмите `Ctrl+P` (Windows) или `Cmd+P` (Mac)
3. В настройках печати:
   - **Принтер:** Сохранить как PDF / Microsoft Print to PDF
   - **Макет:** Портретная ориентация
   - **Размер бумаги:** A4
   - **Поля:** Минимальные или Нет
   - **Фоновая графика:** Включить
   - **Заголовки и колонтитулы:** Отключить
4. Нажмите «Сохранить»

### Способ 2: Google Chrome Headless (автоматизация)

```bash
chrome --headless --disable-gpu --print-to-pdf=catalog.pdf --no-margins file:///C:/Users/Нюся/для%20обучения%20менеджера%20статиста/.business/marketing/catalog-sss/preview.html
```

### Способ 3: Puppeteer (Node.js)

Установите зависимости:
```bash
npm install puppeteer
```

Создайте файл `generate-pdf.js`:
```javascript
const puppeteer = require('puppeteer');

(async () => {
  const browser = await puppeteer.launch();
  const page = await browser.newPage();
  await page.goto('file:///C:/Users/Нюся/для%20обучения%20менеджера%20статиста/.business/marketing/catalog-sss/preview.html', {
    waitUntil: 'networkidle0'
  });
  await page.pdf({
    path: 'catalog-sss.pdf',
    format: 'A4',
    printBackground: true,
    margin: {
      top: '10mm',
      right: '10mm',
      bottom: '10mm',
      left: '10mm'
    }
  });
  await browser.close();
  console.log('PDF сохранён как catalog-sss.pdf');
})();
```

Запустите:
```bash
node generate-pdf.js
```

### Способ 4: wkhtmltopdf

1. Скачайте и установите [wkhtmltopdf](https://wkhtmltopdf.org/)
2. Выполните команду:
```bash
wkhtmltopdf --page-size A4 --margin-top 10 --margin-bottom 10 --margin-left 10 --margin-right 10 --enable-local-file-access preview.html catalog-sss.pdf
```

### Способ 5: Online-конвертеры

Если автоматические способы не работают, можно использовать онлайн-сервисы:
- https://cloudconvert.com/html-to-pdf
- https://www.ilovepdf.com/html_to_pdf
- https://html2pdf.com/

## Настройки для качественного PDF

### Рекомендуемые параметры печати

| Параметр | Значение |
|----------|----------|
| Ориентация | Портретная |
| Размер бумаги | A4 (210 × 297 мм) |
| Поля | Минимальные (5-10 мм) |
| Масштаб | 100% |
| Фоновая графика | Включено |
| Колонтитулы | Отключены |
| Цвет | Цветной |

### Оптимизация для печати

HTML-файл уже содержит оптимизации для печати:
- `@media print` стили для корректного отображения
- Разрывы страниц между секциями
- Отключение ненужных элементов при печати

## Обновление контента

### 1. Обновление структуры

Все изменения в контенте вносите в файл `structure.md`. Это источник истины для каталога.

### 2. Обновление HTML

После изменений в `structure.md` необходимо обновить `preview.html`:
- Либо вручную внести изменения в HTML
- Либо сгенерировать HTML заново (при наличии скрипта конвертации)

### 3. Регенерация PDF

После любых изменений в HTML повторите процедуру генерации PDF.

## Troubleshooting

### Проблема: Логотип не отображается

**Решение:** Убедитесь, что путь к логотипу правильный:
```
src="../../../logo.jpg"
```

Если работаете из другой папки, скорректируйте путь.

### Проблема: Символы emoji не отображаются в PDF

**Решение:** В браузере Chrome/Edge при печати включите опцию «Фоновая графика».

### Проблема: Разрывы страниц не там, где нужно

**Решение:** HTML содержит стили `page-break-inside: avoid` для категорий. Если проблема сохраняется, попробуйте:
- Использовать другой браузер (Chrome обычно работает лучше всего)
- Уменьшить масштаб печати до 95%

### Проблема: Фон не печатается

**Решение:** Включите «Фоновую графику» в настройках печати.

## Поддержка

При возникновении вопросов:
1. Проверьте актуальность путей к файлам
2. Убедитесь, что используете современный браузер
3. Попробуйте другой способ генерации PDF
