# Папка plans/

Это место для технических планов реализации функций проекта.

**Правила:**

- Один план = одна функция. Если план уже есть — работаем с ним.
- Формат имени файла: `YYYY-MM-DD-название-функции.md`
- Каждый план делится на фазы. У каждой фазы статус `[ ]` (не сделано) или `[x]` (сделано).
- В конце плана — итоговый блок: реализован целиком или нет, что осталось.
- Любой агент, работающий с планом, обязан его актуализировать: отмечать сделанные фазы, дописывать что сделал.
