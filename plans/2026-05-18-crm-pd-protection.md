# План: Защита персональных данных в CRM

**Дата:** 2026-05-18
**Статус:** [WIP]

## Цель

Обеспечить соответствие CRM системы требованиям 152-ФЗ «О персональных данных» и РКН (Роскомнадзор). Персональные данные хранятся и обрабатываются только на серверах в РФ, в git - только обезличенные демо-данные.

## Классификация данных в CRM

### Публичные данные (НЕ ПД, можно в git)
- Название компании (ООО «Кнауф Гипс» и т.д.)
- ИНН (публичные данные ЕГРЮЛ)
- Город
- Website
- Направление деятельности
- Должность контакта (без ФИО)

### Персональные данные (ПД, 152-ФЗ, ТОЛЬКО локально / РФ-серверы)
- ФИО контактов
- Телефоны контактов
- Email контактов

### Коммерческая тайна (НЕ в git, только локально)
- Суммы сделок
- Заметки о переговорах (с конкретными деталями)
- Условия поставок

## Требования 152-ФЗ (РКН)

### Что уже соблюдается
1. Данные не покидают РФ (Amvera - РФ-серверы, Vercel - требует проверки)
2. ПД не попадают в публичный git-репозиторий
3. Доступ к данным только у авторизованных пользователей CRM

### Что нужно проверить
1. **Vercel деплой CRM** - серверы Vercel могут быть за рубежом. Рассмотреть полный переход на Amvera для продакшн CRM с реальными данными.
2. **Уведомление в РКН** - при обработке ПД нужно уведомить Роскомнадзор (если ещё не сделано)
3. **Согласие на обработку ПД** - форма согласия для контактов клиентов
4. **Политика конфиденциальности** - документ для сайта/CRM

### Инфраструктура: только РФ-серверы

| Среда | Платформа | Серверы | ПД разрешены |
|-------|-----------|---------|--------------|
| Разработка | Локальная машина | Да | Да |
| CRM демо | Vercel | Нет (USA/EU) | Нет (только demo.json) |
| CRM продакшн | Amvera | Да (РФ) | Да |
| Сайт | GitHub Pages | Нет | Нет (нет ПД) |

**Важно:** для продакшн CRM с реальными ПД - использовать ТОЛЬКО Amvera (РФ-серверы). Vercel - только для демо с обезличенными данными.
