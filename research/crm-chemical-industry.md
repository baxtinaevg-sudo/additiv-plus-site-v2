## Ключевые выводы

### Специфика индустрии

| Характеристика | Значение |
|---------------|----------|
| Длина цикла сделки | 6-18 месяцев |
| Кол-во decision makers | 3-5 человек |
| Уникальные этапы | Инженерная оценка → Лабораторные тесты → Полевые испытания |
| Compliance | Обязательный учёт регуляторных требований |

### Этапы воронки для строительной химии

```
1. Лид (первичный контакт)
2. Квалификация (подходит ли клиент)
3. Техническая оценка (инженерные требования)
4. Лабораторные тесты (подбор рецептуры)
5. Полевые испытания (тестирование на объекте)
6. Коммерческое предложение
7. Переговоры (согласование цены и условий)
8. Закрытие (договор/отказ)
```

## Применение к Аддитив Плюс

### Что учесть в CRM

| Требование | Реализация |
|------------|------------|
| Длинный цикл | Timeline сделки в днях/месяцах |
| Лабораторные тесты | Статус "В лаборатории" в сделке |
| Полевые испытания | Статус "Полевое тестирование" |
| Compliance | Поле "Регуляторные требования" в карточке клиента |
| Multiple decision makers | Множество контактов на клиента |

### Обновлённая воронка для Аддитив Плюс

```
Новый лид → Квалификация → Тех. оценка → Лаборатория →
Полевые испытания → КП → Переговоры → Сделка/Провал
```
