# Интеграция 1С с CRM: ресерч

**Дата:** 2026-05-25
**Цель:** Изучить варианты интеграции 1С:Предприятие с веб-CRM

---

## Ключевые выводы

### Методы интеграции

| Метод | Описание | Сложность |
|-------|----------|-----------|
| **REST API** | Стандартный HTTP-интерфейс 1С | Средняя |
| **HTTP-сервисы** | Кастомные endpoints в 1С | Высокая |
| **Webhooks** | Push-уведомления от 1С | Средняя |
| **Файловый обмен** | XML/CSV через папку | Низкая |

### REST API в 1С:Предприятие

1С:Предприятие предоставляет встроенный REST API для обмена данными.

**Базовые endpoint'ы:**
- `GET /hs/rest/{object}` - чтение данных
- `POST /hs/rest/{object}` - создание
- `PUT /hs/rest/{object}` - обновление
- `DELETE /hs/rest/{object}` - удаление

## Архитектурные паттерны

### Вариант 1: Прямая интеграция

```
CRM ←→ 1С:Предприятие (REST API)
```

**Плюсы:**
- Реальный тайм
- Минимум middleware

**Минусы:**
- Зависимость от доступности 1С
- Сложная аутентификация

### Вариант 2: Через middleware

```
CRM ←→ API Gateway ←→ 1С:Предприятие
```

**Плюсы:**
- Кеширование
- Балансировка нагрузки
- Безопасность

**Минусы:**
- Ещё одна точка отказа
- Дороже в разработке

### Вариант 3: Асинхронный обмен

```
CRM → Message Queue → 1С
CRM ← Message Queue ← 1С
```

**Плюсы:**
- Надёжность
- Масштабируемость

**Минусы:**
- Delay в данных
- Сложность

## Сценарии обмена для Аддитив Плюс

### Bidirectional sync

| Направление | Данные | Частота |
|-------------|--------|---------|
| CRM → 1С | Новые клиенты, сделки | Realtime |
| 1С → CRM | Счета, отгрузки, оплаты | Hourly |
| CRM → 1С | Заявки в лабораторию | Realtime |
| 1С → CRM | Статусы заявок, протоколы | Realtime |

### Модель данных для синхронизации

**Клиент:**
- ИНН (ключ)
- Название
- Адрес
- Контакты

**Сделка:**
- ID сделки (CRM)
- ID клиента
- Сумма
- Статус
- Продукты

**Счёт:**
- Номер счёта
- ID сделки
- Сумма
- Статус

## Технические требования

### Аутентификация

1. **Basic Auth** - простейший вариант
2. **API Key** - лучше для внешних систем
3. **OAuth 2.0** - enterprise вариант

### Авторизация

Права доступа в 1С:
- Пользователь для CRM: только чтение/запись справочников
- Ограничение по IP
- Логирование всех запросов

### Обработка ошибок

- Retry механизм (3 попытки)
- Queue для failed requests
- Алертинг при критических ошибках

## Рекомендуемый подход для Аддитив Плюс

### Фаза 1: Файловый обмен (MVP)

```
1C → CSV → CRM (импорт раз в час)
CRM → CSV → 1C (экспорт новых записей)
```

**Срок:** 1-2 недели
**Стоимость:** Минимально

### Фаза 2: REST API интеграция

```
CRM ←→ 1С REST API (прямое подключение)
```

**Срок:** 2-4 недели
**Стоимость:** Средняя

### Фаза 3: Enterprise решение

```
CRM ←→ Message Queue ←→ 1С
```

**Срок:** 1-2 месяца
**Стоимость:** Высокая
