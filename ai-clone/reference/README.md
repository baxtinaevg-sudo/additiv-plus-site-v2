# 🔧 reference/ — Инструменты и инфраструктура

> Здесь живёт справочная информация об инструментах, сервисах и инфраструктуре. **Без секретов и паролей.**

## Правило

❌ **Никаких паролей, API-ключей, токенов.**
✅ Только названия инструментов, ссылки, описание назначения.

## Формат

Создавай файлы по категориям или отдельным инструментам:

```markdown
# [Название инструмента]

## Что делает
<!-- Краткое описание функциональности. -->

## Почему выбрал(а)
<!-- Обоснование выбора. -->

## Как использую
<!-- Типичный сценарий использования. -->
```

## Примеры категорий

- **Разработка:** IDE, терминал, Git-хостинг
- **Дизайн:** Figma, графические инструменты
- **Продуктивность:** нотатки, задачи, календарь
- **Коммуникация:** мессенджеры, почта
- **Инфраструктура:** хостинг, CI/CD, мониторинг
- **AI-инструменты:** модели, промпты, автоматизации

---

_Инструменты — это расширения возможностей. Знай свой арсенал._
