# 🏛 mastery/ — Чужие методологии

> Здесь живёт разбор подходов великих — тех, чьи идеи я перенимаю и адаптирую.

## Зачем эта папка

Никто не изобретает с нуля. Лучшие практики — это осознанный выбор чужих проверенных методологий, адаптированных под себя.

## Формат файла

Создавай отдельный файл на каждую методологию или человека:

```markdown
# [Имя / Название методологии]

## Суть
<!-- 2–3 предложения: в чём метод. -->

## Что я беру
<!-- Конкретные практики, которые применяю. -->

## Что не беру
<!-- Что не подходит и почему. -->

## Как применяю
<!-- Мой способ адаптации под свои задачи. -->
```

## Примеры методологий для разбора

- First Principles (Илон Маск)
- Инверсия (Чарли Мангер)
- Deep Work (Кэл Ньюпорт)
- Lean Startup (Эрик Рис)
- Getting Things Things Done (Дэвид Аллен)
- Building a Second Brain (Тиаго Форте)
