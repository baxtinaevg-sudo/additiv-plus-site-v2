# 💻 code.md — Принципы кода

> Мои правила в технической работе и коде.

## Стиль написания

- **Скорость** — быстро написал, быстро проверил, быстро поправил. Итеративный подход.
- **Структура** — всё организовано логично. Файлы, папки, naming — порядок.
- Не хаос, а быстрый порядок.

## Инструменты и автоматизация

- Изучаю новые инструменты с интересом — но внедряю только если реально экономит время.
- Если стандартное решение не подходит — строю своё. Не впихиваю квадратное в круглое.
- Прагматичный подход: инструмент — средство, не цель.

## Что важно

- Результат важнее идеальности кода.
- Структура важнее красоты.
- Работает → организовано → можно улучшать.
