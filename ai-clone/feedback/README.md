# 📝 feedback/ — Правила, выученные через ошибки

> Здесь живут правила, полученные из реального опыта и ошибок.
> Эта папка — **память** AI-клона. Каждое правило — урок, который не нужно повторять.

## Формат каждого правила

Создавай отдельный `.md` файл на каждое правило (или группу связанных правил).

```markdown
# [Название правила]

## Правило
<!-- Чёткая формулировка: что делать или чего не делать. -->

## Почему
<!-- Контекст ошибки или наблюдения. Что произошло, когда правило нарушили. -->

## Как применить
<!-- Конкретные шаги или чеклист для применения правила. -->
```

## Пример

```markdown
# Не обещать сроки без буфера

## Правило
Всегда добавляй 30% буфера к любой оценке сроков.

## Почему
Трижды оценивал проект в 2 недели — каждый раз уходило 3+.
Причины: незапланированные правки, зависимость от третьих лиц, недооценка тестирования.

## Как применить
1. Оцени реалистичный срок.
2. Умножь на 1.3.
3. Если результат звучит «слишком долго» — всё равно так и скажи.
```

---

## Как пополнять

1. После каждой ошибки — сформулируй правило.
2. Запиши в новый файл по шаблону выше.
3. При следующей задаче — AI прочитает `feedback/` и учтёт уроки.

_Ошибки бесплатны, только если из них учишься._
