# Методология mastery

## Принцип

**Один автор = один файл. Только методы, не пересказ.**

Мы не пишем конспекты книг. Мы извлекаем 1–3 самых мощных метода каждого автора и формулируем их так, чтобы можно было применить немедленно.

## Зачем

Чтобы в любой момент открыть нужную область и получить совет от лучших практиков — как от личного совета директоров.

## Как пользоваться

1. **Нужна идея или решение** → открой нужную область в `mastery/`
2. **Прочитай метод** → каждый файл содержит только выжимку
3. **Примени** → методы сформулированы как действия, не как теория

## Правила наполнения

- **Один автор — один файл.** Не смешиваем разных людей в одном файле.
- **Только методы.** Никаких биографий, контекста, «интересно отметить». Только: что делать и как.
- **1–3 метода на автора.** Если метода больше — значит, это пересказ. Оставить самое сильное.
- **Язык формул.** Каждый метод = краткая формула + когда применять + пример.
- **Область = папка.** Новая область — новая папка. Не плодить файлы в корне.

## Формат файла автора

```markdown
# Имя Автора

> Краткая формула автора (1 предложение)

## Метод 1: Название

**Формула:** ...
**Когда применять:** ...
**Пример:** ...

## Метод 2: Название

**Формула:** ...
**Когда применять:** ...
**Пример:** ...
```

## Что не попадает в mastery

- Пересказы книг и статей
- Общие рассуждения без конкретики
- Методы без примера применения
- Всё, что можно найти в Google за 30 секунд
