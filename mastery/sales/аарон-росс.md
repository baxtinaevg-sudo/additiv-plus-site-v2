## Метод 1: Cold Calling 2.0

**Суть:** Холодные звонки не работают, когда один человек ищет лиды, квалифицирует, проводит демо и закрывает. Разделите процесс на специализации — и каждый этап станет в 3-5 раз эффективнее.

**Шаги:**

1. **Создайте роль SDR (Sales Development Rep).** Этот человек ТОЛЬКО ищет лиды и назначает встречи. Не продаёт, не закрывает, не демонстрирует продукт. Единственная метрика — количество квалифицированных встреч.
2. **Создайте роль AE (Account Executive).** Этот человек ТОЛЬКО проводит встречи и закрывает сделки. Получает лиды от SDR, ведёт через SPIN/презентацию/переговоры до подписания.
3. **SDR работает по узким сегментам.** Не «все, кто может купить», а «директора по производству в компаниях 50-200 человек в пищевой промышленности». Чем уже сегмент — тем лучше скрипт.
4. **Скрипт SDR: 30 секунд, 0 продаж.** «Привет, [Имя]. Я [Компания]. Мы помогаем [тип компаний] [решить конкретную проблему]. Сейчас не продаю — просто узнаю, актуально ли. Если да — назначу звонок с экспертом. Актуально?»
5. **Измеряйте воронку:** SDR → встреча → квалификация → предложение → закрытие. На каждом этапе — конверсия. Если конверсия падает — проблема в конкретном переходе, а не «в продажах вообще».

**Когда применять:**
- Компания выросла до 10+ сотрудников и нужно систематизировать продажи
- Один «универсальный» продавец не справляется с объёмом
- Нужен предсказуемый поток лидов, а не «то густо, то пусто»

**Связи:** [[чет-холмс]] — Dream 100 даёт SDR целевой список для Cold Calling 2.0. [[нил-рекхэм]] — AE использует SPIN на встречах, которые назначил SDR.

## Метод 2: Predictable Revenue Formula (Формула предсказуемой выручки)

**Суть:** Выручка = Количество сделок × Средний чек × Частота покупки. Управляя каждым элементом отдельно, можно прогнозировать рост на кварталы вперёд.

**Формула:**

```
Выручка = Лиды × Конверсия × Средний чек × Repeat
```

**Шаги:**

1. **Измерьте каждый элемент** за последние 3-6 месяцев. Без базовых цифр невозможно прогнозировать. Сколько лидов? Какая конверсия в сделку? Средний чек? Повторные покупки?
2. **Выберите один рычаг для роста** на текущий квартал. Не пытайтесь улучшить всё сразу:
   - Мало лидов → стройте Outbound-машину (Cold Calling 2.0)
   - Низкая конверсия → улучшайте скрипты и SPIN-навыки
   - Маленький чек → переструктурируйте оффер (Grand Slam Offer)
   - Нет повторных → стройте retention-процесс
3. **Поставьте целевую цифру** на квартал: «Растим количество лидов с 50 до 80 за квартал». Одна цифра, один рычаг.
4. **Еженедельный замер** — каждый понедельник смотрите: продвигается ли целевая метрика. Если нет за 2 недели — меняйте подход.
5. **После достижения цели — переключайтесь** на следующий рычаг. Рост = последовательное улучшение по одному параметру.

**Когда применять:**
- Когда продажи хаотичны и непредсказуемы
- При планировании квартальных целей
- Когда нужно объяснить руководству/инвесторам, откуда возьмётся рост

**Связи:** [[алекс-хормози]] — Grand Slam Offer влияет на средний чек и конверсию. [[чет-холмс]] — Dream 100 сфокусированно увеличивает количество и качество лидов.

## Метод 3: Specialisation by Segment (Специализация по сегментам)

**Суть:** Продавец, который продаёт «всем», продаёт никому. Разделите команду по отраслям/размерам компаний — и каждый станет экспертом в своём сегменте с персонализированным подходом.

**Шаги:**

1. **Проанализируйте закрытые сделки** за последний год: какие клиенты закрываются быстрее, платят больше, реже уходят? Это ваш идеальный сегмент.
2. **Выделите 2-3 ключевых сегмента** по отрасли, размеру или типу потребности. Пример: «Пищевое производство 50-200 человек» / «Строительные компании 100-500» / «Дистрибьюторы».
3. **Закрепите за каждым сегментом отдельного продавца/команду.** Этот человек знает терминологию, боли, типичные возражения и кейсы отрасли.
4. **Создайте сегмент-специфичные материалы:** скрипты, кейсы, Core Story, офферы — всё адаптировано под конкретную отрасль.
5. **Сравнивайте эффективность** между сегментами через 3 месяца. Усиливайте работающие, сокращайте неработающие.

**Когда применять:**
- Когда один продавец «разрывается» между разными типами клиентов
- Когда скрипты и кейсы слишком общие и не резонируют с клиентом
- При масштабировании команды от 3 продавцов

**Связи:** [[чет-холмс]] — Dream 100 естественным образом группируется по сегментам. [[нил-рекхэм]] — каждый сегмент требует своего SPIN-сценария с типовыми Problem и Implication вопросами. [[алекс-хормози]] — Value Equation для каждого сегмента будет иметь разные Dream Outcome и барьеры.
