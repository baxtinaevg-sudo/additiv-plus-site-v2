# sales/ — Продажи

Карта методов продаж от признанных практиков. Не «мотивация» и не «искренность продаёт», а конкретные системы и алгоритмы.

## Авторы

| Автор | Ключевая идея | Файл |
|-------|--------------|------|
| **Чет Холмс** | Продажи через образование и системный фокус на 100 лучших клиентах | [[чет-холмс]] |
| **Алекс Хормози** | Создание офферов, от которых глупо отказываться | [[алекс-хормози]] |
| **Нил Рекхэм** | Научно обоснованные продажи через SPIN-вопросы | [[нил-рекхэм]] |
| **Джим Кэмп** | Переговоры с позиции силы: начинай с «нет» | [[джим-кэмп]] |
| **Аарон Росс** | Предсказуемая система outbound-продаж через разделение ролей | [[аарон-росс]] |

## Как авторы связаны

```
Холмс (Dream 100) ──────→ Росс (Cold Calling 2.0)
     │                          │
     │ (Core Story)             │ (SDR → AE)
     ↓                          ↓
Хормози (Grand Slam Offer) ←──→ Рекхэм (SPIN)
     │                          │
     │ (Top-Down Pricing)       │ (Профилактика возражений)
     ↓                          ↓
Кэмп (Start with No) ←──── Обработка давления и возражений
```

## Поток применения

1. **Создайте оффер** → [[алекс-хормози]] (Grand Slam Offer)
2. **Определите цели** → [[чет-холмс]] (Dream 100)
3. **Выстройте систему outreach** → [[аарон-росс]] (Cold Calling 2.0)
4. **Ведите встречи** → [[нил-рекхэм]] (SPIN)
5. **Закрывайте и торгуйтесь** → [[джим-кэмп]] (Start with No)
